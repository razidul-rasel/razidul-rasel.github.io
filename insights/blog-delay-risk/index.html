Applying Machine Learning to Software Project Delay Risk

My MSc research, Software Project Delay Risk Prediction Using Machine Learning, explored multi-class delay-risk classification using a publicly available project-management dataset.

The study compared Logistic Regression, Random Forest, and Gradient Boosting. The workflow included preprocessing, feature engineering, model tuning, stratified train-test evaluation, and cross-validation. Performance was assessed using accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.

Results should be interpreted in the context of the dataset and experimental setup. Dataset provenance, predefined risk labels, and the availability of actual timeline outcomes are important limitations.
