MSc RESEARCH · 2025–2026

Software Project Delay Risk Prediction Using Machine Learning

MSc in Computer Science and Engineering · Jahangirnagar University

Investigated machine-learning approaches for multi-class software project delay-risk classification using a publicly available project-management dataset. The study compared supervised learning models and examined the role of project characteristics in delay-risk categories.

Methods and workflow

  • Data preprocessing and feature engineering
  • Logistic Regression, Random Forest, and Gradient Boosting
  • Stratified train-test evaluation and cross-validation
  • Hyperparameter tuning and comparative evaluation
  • Feature-importance analysis

Evaluation

  • Accuracy, precision, recall, and F1-score
  • ROC-AUC and confusion matrix
  • Analysis of model performance and limitations

Reported result: tuned Gradient Boosting model. The study also identified limitations related to dataset provenance, predefined risk labels, and availability of actual project timeline outcomes.
